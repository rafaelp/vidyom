# AGENTS.md

Instructions for AI coding agents working in this repository. Humans should start with [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).

## Project status

Vidyom is an open-source, AI-powered video workflow engine at the **specification stage**. No runtime code exists yet: `vidyom`, `vidyomd`, `vidyom-worker`, the daemon API, the workflow nodes and every command shown in the docs are **proposed interfaces**. Never write documentation, examples or comments that present them as implemented.

## Repository layout

- `spec/`: the complete product specification the website was derived from. `vidyom-specification-v1.1.md` is current; v1.0 is kept for history. §17 lists pending decisions and §20 is the v1.1 revision log.
- `website/`: Docusaurus 3 site (TypeScript, React 19).
  - `docs/`: specification pages, one folder per sidebar category. The sidebar is autogenerated from the folders (`sidebars.ts`).
  - `examples/`: illustrative, non-executable workflow, configuration and media profile JSON.
  - `src/pages/index.tsx`: home page. `src/css/custom.css`: theme and brand colors.
  - `static/img/`: logos, favicon and the workflows overview image.
- `.github/`: CI (`workflows/docs.yml`), Dependabot, issue and pull request templates.
- Root community files: `README.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `LICENSE` (Apache-2.0) and `NOTICE`.

Runtime code will be added alongside `website/`, following the proposed layout in `website/docs/architecture/repository.md`.

## Commands

Run from `website/` with Node.js 20+ (Node 22 recommended):

```bash
npm install
npm run start       # dev server at http://localhost:3000
npm run typecheck   # tsc --noEmit
npm run build       # production build; fails on broken links
```

CI runs `npm ci`, `npm run typecheck` and `npm run build` on every push and pull request. Run `typecheck` and `build` before finishing any change under `website/`.

## Writing rules

- Everything is written in **English**: documentation, code, comments, UI copy and commit messages.
- Mark requirement status with **Decided**, **Proposed**, **Future** or **Validate** (the spec writes them as `[DECIDED]`, `[PROPOSED]`, `[FUTURE]`, `[VALIDATE]`). Never promote a Proposed item to Decided on your own.
- Do not fill pending decisions silently. Open items are listed in `website/docs/reference/open-questions.md` and spec §17. If a change depends on one, flag it instead of choosing.
- When the website and the spec disagree, point it out rather than resolving it silently. Known example: the spec uses the `COR-` prefix for clip IDs, while the website uses `CLIP-`.
- Use fictional examples (`ORI-001`, `media.example.internal`). Never include real credentials, tokens, signed URLs or personal data.
- Every docs page needs frontmatter with `title` and `sidebar_position`. Link between docs with relative Markdown paths (`./workflows/create-clip.md`); `onBrokenLinks` is set to `throw`.

## Domain vocabulary

Keep these concepts distinct (see `website/docs/getting-started/concepts.md` and `website/docs/connectors/overview.md`):

- **Node** (workflow action), **connector** (provider driver), **plugin** (distributable package), **hook** (synchronous lifecycle interception) and **event** (asynchronous notification).
- Storage roles `archive`, `master` and `proxy`. Clipping must **never** read from `archive`.
- An **original** is any ingested recording, not only a lecture. Every clip is its own asset with lineage back to its source.

## Website styling

- Brand colors are CSS variables in `website/src/css/custom.css`: light-mode primary `#c54b00`, dark-mode primary `#fd8a02` (the logo orange), warm near-black dark backgrounds (`#15110f`).
- Dark-mode overrides must use the `html[data-theme='dark']` selector; plain `[data-theme='dark']` loses to Infima's defaults.
- The navbar uses `img/vidyom-logo.png` and, in dark mode, `img/vidyom-logo-dark.png` (light wordmark).
- In React pages, reference static assets through `useBaseUrl`, because `baseUrl` is configurable via `DOCS_BASE_URL`.

## Git

- The default branch is `main`; the GitHub repository is `rafaelp/vidyom`.
- Write commit messages in English, in the imperative mood.
- Security issues are reported privately as described in `SECURITY.md`, never in public issues.
